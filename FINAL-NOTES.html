The flow

  • LaunchiPhone home screen → splash → three intro slides (skippable)
  • Sign inOne phone screen (WhatsApp or SMS) → 6-digit code → new patients add name, email and consent → location (Continue, or type an address) → Home
  • TabsHome · Appointments · Chat · Profile. Cart is an icon in the Home header; Membership and Medical reports open from Profile
  • HomeVisit address, search, alerts and cart in the header → Doctor on Call → video consult → services grid → upcoming visit with live tracking → one offer
  • SearchSearch icon → overlay with recent and popular searches, live results as you type
  • BookingService → detail → cart with each item pre-filled (you, Home, next slot) → Pay → Done
  • AppointmentsOne details page that follows the visit: assigning → on the way (map, driver, plate) → arrived → in progress → completed (team, reports, prescription, invoice, rating)
  • ChatFRH Support always on top, then one thread per visit; 998 always visible
